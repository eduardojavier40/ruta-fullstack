# 00-fundamentos / logica-de-programacion

Los bloques de construcción de cualquier lenguaje de programación. No importa si después programas en JavaScript, Python o Java — esta lógica es la misma en todos.

## Progreso

- [ ] Variables, tipos de datos, operadores
- [ ] Condicionales y bucles
- [ ] Funciones y estructuras de datos (arrays, objetos)

---

## 1. Variables, tipos de datos, operadores

**Qué vas a entender al terminar este tema:**
- Qué es una variable y por qué se dice que "guarda" un valor.
- Los tipos de datos básicos: número, texto (string), booleano (verdadero/falso).
- Operadores aritméticos (`+ - * /`) y de comparación (`== > < >=`).
- La diferencia entre asignar un valor (`=`) y comparar (`==`).

## 2. Condicionales y bucles

**Qué vas a entender al terminar este tema:**
- Cómo un programa toma decisiones con `if / else`.
- Por qué existen los bucles (`for`, `while`) — repetir una acción sin copiar el mismo código muchas veces.
- Cuándo usar un `for` (sabes cuántas veces repetir) versus un `while` (repites hasta que se cumpla una condición).

## 3. Funciones y estructuras de datos

**Qué vas a entender al terminar este tema:**
- Qué es una función: un bloque de código reutilizable que recibe entradas (parámetros) y devuelve una salida.
- Arrays (listas ordenadas de valores) y cómo recorrerlos.
- Objetos (pares clave-valor) y cómo acceder a sus propiedades.
